Inferência estatística e comparação com a população

Intervalos de confiança e testes usam somente a amostra (AAS, n = 382). O parâmetro populacional é calculado diretamente e aparece só para comparação.

🎯 O que estamos fazendo aqui? (a ideia em 4 passos)
  1. Fingimos que não conhecemos a população. Na vida real quase nunca temos todos os dados, só uma amostra.
  2. Com as 382 partidas sorteadas, estimamos um número da população, como a % de vitórias do favorito. Damos um palpite (a estimativa pontual) e uma margem em volta dele (o intervalo de confiança, IC).
  3. Testamos uma afirmação (a hipótese H₀, por exemplo "o favorito vence só 50%"). O valor-p responde: se H₀ fosse verdade, qual a chance de uma amostra mostrar algo tão extremo quanto o que vimos? Se essa chance for menor que α, consideramos H₀ improvável e a rejeitamos.
  4. Conferimos com a população. Como temos as 66.819 partidas, dá para ver se o IC "acertou" o valor real e se a decisão do teste foi correta. Isso é impossível na prática, mas ótimo para aprender.
Nível de significância (α)
Os ICs são de 95%. O padrão do trabalho é α = 5%.
