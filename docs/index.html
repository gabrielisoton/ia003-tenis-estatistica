Quantas partidas sortear?

Tamanho para estimar uma proporção (a mesma fórmula da calculadora USP/Bauru):

  • Confiança de 95% (z = 1,96), o padrão em pesquisas.
  • Margem de erro de 5 pontos percentuais.
  • p = 0,5: sem informação prévia, é o valor que maximiza p(1−p). É o caso mais conservador.
